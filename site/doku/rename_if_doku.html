rename_if.sh

Shell-Script, das in einer OPNsense-Konfigurationsdatei (config.xml) die Interface-Namen von emX nach igbX umbenennt – z. B. nach einem Wechsel von virtuellen bzw. älteren Intel-NICs (Treiber em) auf Intel-Gigabit-NICs (Treiber igb).

1. Zweck

OPNsense ordnet logische Interfaces (WAN, LAN, OPT1 …) über den physischen Gerätenamen zu, etwa <if>em0</if>. Ändert sich der Netzwerktreiber, heißen die Geräte anders und die Zuordnung greift nicht mehr. Das Script passt alle Vorkommen in der Konfiguration an, sodass sie nach einem Neustart wieder zu den Geräten passt. Die Nummer bleibt dabei erhalten: em0 → igb0, em1 → igb1 usw.

2. Voraussetzungen

  • POSIX-Shell (/bin/sh). Bash wird nicht benötigt – auf OPNsense ist sie standardmäßig nicht installiert.
  • Standardwerkzeuge sed, cmp, diff, cp (auf OPNsense/FreeBSD vorhanden).
  • Optional xmllint: Ist es vorhanden, wird das Ergebnis vor dem Schreiben auf gültiges XML geprüft.
  • Schreibrechte auf die Zieldatei (für /conf/config.xml: root).

3. Aufruf und Optionen

sh rename_if.sh [-f DATEI] [ALT] [NEU]
ParameterBedeutungStandard
-f DATEIZu bearbeitende Konfigurationsdatei./config.xml (aktuelles Verzeichnis)
ALTBisheriges Treiber-Präfixem
NEUNeues Treiber-Präfixigb
-hKurzhilfe anzeigen–

ALT und NEU dürfen nur Kleinbuchstaben enthalten.

Beispiele

# config.xml im aktuellen Verzeichnis, em -> igb
sh rename_if.sh

# Live-Konfiguration der Firewall
sh rename_if.sh -f /conf/config.xml

# Exportierte Sicherung, anderes Präfixpaar
sh rename_if.sh -f config-export.xml em ix

# Hilfe
sh rename_if.sh -h

4. Ablauf

  1. Prüft, ob die Datei existiert und beschreibbar ist.
  2. Erzeugt eine geänderte Kopie in einer temporären Datei; das Original bleibt bis zur Bestätigung unverändert.
  3. Bricht ohne Änderung ab, wenn keine passenden Interface-Namen gefunden wurden.
  4. Prüft das Ergebnis mit xmllint (falls vorhanden).
  5. Zeigt alle Änderungen als diff und fragt nach Bestätigung (j/y). Jede andere Eingabe bricht ab.
  6. Legt ein Backup DATEI.bak-JJJJMMTT-HHMMSS neben der Originaldatei an.
  7. Schreibt das Ergebnis in die Originaldatei (Dateirechte und Besitzer bleiben erhalten) und gibt den Befehl zum Zurücksetzen aus.

5. Was ersetzt wird – und was nicht

Ersetzt wird ein Name nur, wenn er als eigenständiger Wert steht:

Eingabe config.xml (gekürzt):

  <interfaces>
    <wan><if>em0</if></wan>
    <lan><if>em1</if></lan>
  </interfaces>
  <vlans>
    <vlan><if>em1</if><tag>10</tag><vlanif>em1_vlan10</vlanif></vlan>
  </vlans>

7. Vorgehen auf der Firewall

  1. Vorab eine Sicherung über die Weboberfläche ziehen: System → Konfiguration → Sicherungen → Herunterladen.
  2. Script per SCP auf die Firewall kopieren, z. B. nach /root/.
  3. Per SSH oder Konsole als root anmelden (Menüpunkt 8) Shell).
  4. Script ausführen: 
    sh /root/rename_if.sh -f /conf/config.xml
  5. Diff prüfen und mit j bestätigen.
  6. Neu starten: reboot
  7. Nach dem Start Zuordnung unter Schnittstellen → Zuweisungen kontrollieren.

Konsolenzugang bereithalten. Stimmt die neue Zuordnung nicht, ist die Firewall unter Umständen nicht mehr über das Netzwerk erreichbar.

Alternativ lässt sich eine exportierte config.xml auf einem anderen Rechner umschreiben und anschließend über Sicherungen → Wiederherstellen einspielen.

8. Zurücksetzen

Das Script gibt den passenden Befehl am Ende aus. Allgemein:

cp /conf/config.xml.bak-JJJJMMTT-HHMMSS /conf/config.xml
reboot

Zusätzlich kann jederzeit die vorab heruntergeladene Sicherung über die Weboberfläche oder die Konsole (Menüpunkt 13) Restore a backup) eingespielt werden.

10. Grenzen und Hinweise

  • Reihenfolge der Ports: Das Script übernimmt die Nummer 1:1. Ob igb0 physisch derselbe Port ist wie vorher em0, hängt von der Hardware ab. Vor dem Umbau mit ifconfig bzw. anhand der MAC-Adressen prüfen.
  • Anzahl der Ports: Hat die neue Hardware weniger Ports, verweisen überzählige Einträge auf nicht vorhandene Geräte und müssen manuell angepasst werden.
  • Ungewöhnliche Schreibweisen: Namen in anderer Umgebung als oben beschrieben (z. B. em0: oder innerhalb von Anführungszeichen) werden nicht erfasst. Der Diff zeigt, was tatsächlich geändert wird.
  • Interaktiv: Das Script erwartet eine Bestätigung über die Tastatur. Für unbeaufsichtigte Läufe echo j | sh rename_if.sh … verwenden.
  • Neustart nötig: Änderungen an /conf/config.xml werden erst nach einem Neustart wirksam.

11. Quelltext

rename_if.sh 
#!/bin/sh
# Benennt Interface-Namen in der OPNsense-Konfiguration um (Standard: emX -> igbX).
# Die Nummer bleibt erhalten: em0 -> igb0, em1 -> igb1, em0_vlan10 -> igb0_vlan10 ...
#
# Arbeitet standardmaessig auf config.xml im aktuellen Verzeichnis.
#
# Aufruf:   sh rename_if.sh [-f DATEI] [ALT] [NEU]
# Beispiel: sh rename_if.sh -f /conf/config.xml
#           sh rename_if.sh -f backup.xml em igb

usage() {
    echo "Aufruf: sh $0 [-f DATEI] [ALT] [NEU]"
    echo "  -f DATEI  Konfigurationsdatei (Standard: ./config.xml)"
    echo "  ALT NEU   Interface-Praefixe (Standard: em igb)"
}

CONF="./config.xml"
while getopts "f:h" OPT; do
    case "$OPT" in
        f) CONF="$OPTARG" ;;
        h) usage; exit 0 ;;
        *) usage >&2; exit 1 ;;
    esac
done
shift $((OPTIND - 1))

OLD="${1:-em}"
NEW="${2:-igb}"

STAMP=$(date +%Y%m%d-%H%M%S)
BACKUP="${CONF}.bak-${STAMP}"
TMP="${CONF}.tmp-$$"

die() { echo "FEHLER: $*" >&2; rm -f "$TMP"; exit 1; }

[ -f "$CONF" ] || die "Konfiguration nicht gefunden: $CONF"
[ -w "$CONF" ] || die "Keine Schreibrechte auf $CONF (als root ausfuehren)"
echo "$OLD$NEW" | grep -Eq '^[a-z]+$' || die "ALT/NEU duerfen nur Kleinbuchstaben enthalten"

# Nur ersetzen, wenn der Name als eigenstaendiger Wert steht:
#   davor:  >  ,  Leerzeichen  oder Zeilenanfang
#   danach: <  ,  _  .  Leerzeichen  oder Zeilenende
# Damit bleiben Zertifikate (Base64), Beschreibungen wie "system1" usw. unberuehrt.
# Die Schleife (ta) faengt Listen wie "em0,em1,em2" ab.
sed -E \
    -e ':a' \
    -e "s/(^|[>, ])${OLD}([0-9]+)([<,_. ]|\$)/\\1${NEW}\\2\\3/" \
    -e 'ta' \
    "$CONF" > "$TMP" || die "sed fehlgeschlagen"

[ -s "$TMP" ] || die "Ergebnisdatei ist leer"

if cmp -s "$CONF" "$TMP"; then
    echo "Keine ${OLD}X-Interfaces in $CONF gefunden - nichts zu tun."
    rm -f "$TMP"
    exit 0
fi

# XML pruefen, falls xmllint vorhanden ist
if command -v xmllint >/dev/null 2>&1; then
    xmllint --noout "$TMP" || die "Ergebnis ist kein gueltiges XML - Abbruch"
fi

echo "Folgende Aenderungen werden vorgenommen:"
echo "----------------------------------------"
diff "$CONF" "$TMP"
echo "----------------------------------------"
printf "Aenderungen uebernehmen? [j/N] "
read ANSWER
case "$ANSWER" in
    j|J|y|Y) ;;
    *) echo "Abgebrochen, nichts geaendert."; rm -f "$TMP"; exit 0 ;;
esac

cp -p "$CONF" "$BACKUP" || die "Backup konnte nicht erstellt werden"
cat "$TMP" > "$CONF"    || die "Schreiben fehlgeschlagen - Backup liegt unter $BACKUP"
rm -f "$TMP"

echo "Fertig. Backup: $BACKUP"
echo "Zuruecksetzen: cp $BACKUP $CONF"
echo "Hinweis: Liegt die Datei unter /conf, werden die neuen Namen erst nach einem reboot aktiv."
